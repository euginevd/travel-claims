How UnderCover is built

Three apps, one api and a set of Claude agents on EKS, behind CloudFront, WAF and Cognito, with Bedrock reached privately and every change shipped through a gated pipeline. Locally the same images run in Docker today.

  • No long-lived keys
  • Private subnets only
  • Deny-by-default egress
  • KMS everywhere
  • Separate identity per audience
  • Guardrails + injection check
  • Code pays, never the model
